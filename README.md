# Houston Plumbing Services, LLC

A modern, high-performance web application for **Houston Plumbing Services, LLC** — Houston's trusted Texas Master Plumber (Lic. #40714). Built with React 19, TypeScript, Vite, and Tailwind CSS.

---

## 🌟 Overview

**Houston Plumbing Services** provides premier residential and commercial plumbing solutions across Greater Houston. This web application offers an architectural, responsive experience designed for high conversion, fast load times, and effortless appointment scheduling across desktop, tablet, and mobile devices.

### Key Highlights
- 🛠️ **Texas Master Plumber Certified** (RMP Lic. #40714)
- 🚨 **24/7 Rapid Emergency Dispatch** with sub-60-minute priority windows
- 💧 **Houston Clay Soil & Under-Slab Sewer Specialists** (Camera inspections, hydro-jetting & exterior trenchless tunneling)
- ⚡ **Instant Online Booking & Free Estimate Requests**

---

## 🚀 Features

- **Responsive Multi-Device Layout:** Fully optimized for smartphones, tablets, laptops, and ultra-wide displays with fluid typography and touch-friendly controls.
- **Interactive 60-Second Dispatch Booking:** Instant online scheduling wizard with emergency priority toggles, service categorization, and instant confirmation modal.
- **Free Quote Request Modal:** Interactive quote generator with real-time field validation and direct dispatch triggers.
- **Service Console & Interactive Showcase:** Dynamic category explorer covering:
  - 24/7 Emergency Plumbing Repairs
  - Under-Slab Leak Detection & Tunneling
  - Tankless & Standard Water Heater Systems
  - Hydro-Jetting & Whole-Home Sewer Descaling
  - Gas Line Testing & Whole-Home Repiping
  - Commercial Backflow & Fixture Installations
- **Houston Soil Geology & Sewer Guide:** Technical breakdown of the gulf coast expansive gumbo clay soil challenges and non-destructive plumbing solutions.
- **Verified Customer Reviews:** Interactive testimonials module with star filtering and verified Google local homeowner ratings.
- **Completed Work Gallery:** High-resolution project portfolio showcasing real field installations and repairs.
- **Exclusive Specials & Coupons:** Printable and digitally redeemable seasonal service vouchers.
- **Sticky Mobile Quick-Action Bar:** One-tap emergency calling and instant quote access for on-the-go mobile users.

## 💻 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.0.0` or higher
- **npm** (comes with Node.js) or **bun** / **yarn** / **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/houston-plumbing-services.git
   cd houston-plumbing-services
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to view the application.
